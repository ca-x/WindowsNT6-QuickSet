# 模块结构说明

单文件脚本 `WindowsNT6+快速设置工具.au3`（原 12231 行）已按功能模块拆分，并按系统版本把版本相关实现单独成文件。

命名约定：**目录名小写，模块文件名一律小写、且不重复所在目录的名字**（`src\core\utils.au3` 而不是 `src\core\Core_Utils.au3`）。

## 一、目录结构

```
WindowsNT6+快速设置工具.au3      入口/项目文件：只保留编译指令 + #include 清单
src\
├─ app\                          主流程（顺序敏感，勿调整 include 次序）
│   ├─ init.au3                  全局变量/常量、环境检测、加载动画、托盘菜单、单实例
│   ├─ main_window.au3           主窗口与各选项卡控件创建、事件绑定、初始数据装载
│   └─ main_loop.au3             窗口显示、输入框回调注册、定时器、消息循环
├─ core\                         通用基础库（与业务无关）
│   ├─ utils.au3                 字符串/数组/路径、系统与硬件信息、编解码
│   ├─ win_api.au3               权限提升、LSA、SYSTEM 身份运行、窗口消息过滤
│   ├─ gui.au3                   窗口/控件封装、皮肤与悬停、托盘、消息回调、加载动画
│   ├─ net.au3                   IPHLPAPI 接口表、网卡信息、WMI 适配器、流量统计
│   └─ assets.au3                内嵌资源还原（base64/LZNT → bmp/ico/exe/vbs）
├─ features\                     功能模块，按功能域分目录
│   ├─ net\                      net_tools / ip_set / mac_change / wifi_share / wol / ncsi
│   ├─ system\                   reg_tweaks / plugins / services / ssd / security / cache / process_bl
│   ├─ shell\                    explorer_menu / shell_tweaks / share / dir_transfer
│   ├─ personalize\              oem_info / wallpaper / screen_saver
│   ├─ account\                  user_account / sys_run
│   ├─ license\                  activation
│   └─ tools\                    tray_tools / file_create / dot_net / history / insider / mk_link / force_del / tp_hotkey
├─ os\                           按系统版本的优化实现（见第三节）
│   ├─ common.au3                @OSBuild > 6000 的通用实现与兜底分支
│   ├─ xp.au3                    Windows XP / 2003
│   ├─ vista7.au3                Vista / Win7 / 2008R2（6000 < build ≤ 8000）
│   ├─ win8.au3                  Win8 / 8.1 / 2012（8000 < build ≤ 10240）
│   ├─ win10.au3                 Windows 10（build > 9000）
│   ├─ win11.au3                 Windows 11（build > 19040 / 21900 / 21990）
│   └─ server.au3                Windows Server 专属实现
├─ file\                         运行时载荷（FileInstall 源）与本地 UDF
└─ img\                          图片与图标资源（含编译图标 ToolIco.ico）

docs\                            文档
tools\                           拆分与迁移脚本（一次性使用，可留档）
```

共 46 个模块文件、529 个函数（原 449 个函数 + `src\os` 中拆出的 80 个版本分支函数）。

> `src\file\_GUIDisable.au3`、`src\file\GUICtrlOnHover.au3` 是第三方 UDF，保持原文件名不动。

## 二、编译

入口文件仍在仓库根目录，AccAu3Wrapper 指令（`#PRE_*`）保持不变，直接编译即可：

```
AccAu3Wrapper_GUI 打开 WindowsNT6+快速设置工具.au3 → 编译
```

或使用 AutoIt 自带的 Aut2Exe：

```bat
Aut2exe.exe /in "WindowsNT6+快速设置工具.au3" /out "WindowsNT6+快速设置工具.exe" /x86
Aut2exe.exe /in "WindowsNT6+快速设置工具.au3" /out "WindowsNT6+快速设置工具_x64.exe" /x64
```

> 注：用 Aut2Exe 直接编译时不会写入版本号等资源信息（那是 AccAu3Wrapper 的 `#PRE_Res_*` 指令负责的），
> 程序标题里会显示 V0.0.0.0；用 AccAu3Wrapper 编译则正常显示 1.8.6.6。

## 三、按系统版本的实现（src\os）

原来注册表优化、插件安装等函数里混杂着大量 `If @OSBuild > xxxx Then … Else …` 分支，
现已把**分支正文**整体搬到 `src\os\*.au3`，主流程只保留判断条件 + 一次函数调用：

```autoit
; src\features\system\reg_tweaks.au3 —— AddRegTweaks()
If GUICtrlRead($Checkbox[1]) = $GUI_CHECKED Then
	If @OSBuild < 6000 Then
		_OsXp_AddRegTweaks_01()        ; 见 src\os\xp.au3
	Else
		_OsCommon_AddRegTweaks_02()    ; 见 src\os\common.au3
	EndIf
	$n += 1
EndIf
```

每个生成的函数头部都标注了**适用条件**与**来源**，例如：

```autoit
;-------------------------------------------------------------------------------
; _OsWin11_AddRegTweaks_22
; 适用条件：@OSBuild > 21990
; 来源：AddRegTweaks / 14跳过TPM和安全启动检查
;-------------------------------------------------------------------------------
Func _OsWin11_AddRegTweaks_22()
	RegWrite('HKEY_LOCAL_MACHINE' & $OSFlag & '\SYSTEM\Setup\LabConfig', 'BypassTPMCheck', 'REG_DWORD', '00000001')
	...
EndFunc
```

> 函数名里的 `_OsXxx_` 前缀是「按系统版本拆出来的实现」的标记，与文件名无关。

涉及的文件与条件对照：

| 文件 | 对应条件 |
| --- | --- |
| `xp.au3` | `@OSBuild < 6000`、`@OSVersion = 'WIN_XP' / 'WIN_2003'` |
| `common.au3` | `@OSBuild > 6000` 的通用分支、其余兜底分支 |
| `vista7.au3` | `6000 < @OSBuild ≤ 8000`（含 `ElseIf @OSBuild < 8000 And @OSBuild > 6000`） |
| `win8.au3` | `@OSBuild > 8000` / `@OSBuild < 10240`、`@OSVersion = 'WIN_8' / 'WIN_81'` |
| `win10.au3` | `@OSBuild > 9000`、`@OSVersion = 'WIN_10'` |
| `win11.au3` | `@OSBuild > 19040 / 21900 / 21990` |
| `server.au3` | `@OSVersion = 'WIN_2003' / 'WIN_2008' / 'WIN_2008R2'`，以及 `Win08ServiceTweaks()` |

要改某个系统上的行为，直接打开对应文件即可，不用再在几千行里翻找。

## 四、维护须知

1. **FileInstall 的相对路径以「主脚本所在目录」为基准**（不是当前工作目录，也不是 include 文件所在目录）。
   主脚本在根目录，所以载荷路径写作 `FileInstall('.\src\file\xxx.exe', …)`。
   挪动 `src\file\` 时必须同步修改所有 FileInstall 源路径。
2. **主流程 include 顺序不能改**：`src\app\init.au3` → `main_window.au3` → `main_loop.au3`
   是顶层可执行代码，按顺序执行。其余模块只包含函数定义，顺序无关。
3. **新增模块**：在 `src\features\<功能域>\` 下新建小写文件名的 .au3 后，记得在入口文件的 `#Region` 里加一行 `#include`。
4. 各模块文件顶部有 `#include-once`，模块头注释里写明了模块职责与函数数量。
5. AutoIt 里 `Local` 在文件作用域等价于 `Global`，因此跨 include 使用这些变量是安全的。

## 五、迁移脚本（tools\）

| 脚本 | 作用 |
| --- | --- |
| `split_modules.py` | 从原始单文件脚本重新生成全部模块与入口文件（幂等，需用 `--source` 指定原始脚本） |
| `fix_paths.py` | 目录规范化后的路径修正：`file\` → `src\file\`、`ToolIco.ico` → `src\img\ToolIco.ico`，并校验所有 FileInstall 源文件存在 |
| `split_os_branches.py` | 把 `AddRegTweaks()` / `pluginsTweaks()` 中的版本分支搬进 `src\os\`，并做内容守恒校验 |

原始单文件脚本已从工作区移除（避免仓库里留两份同样的代码），需要时从 git 历史取出：

```bat
git show cbe39cb:"WindowsNT6+快速设置工具.au3" > 原始单文件.au3
python tools\split_modules.py --source 原始单文件.au3
python tools\fix_paths.py
python tools\split_os_branches.py --apply
```

三个脚本都带校验：

- `split_modules.py`：449 个函数必须全部有归属，且拆分前后内容逐行一致；
- `fix_paths.py`：45 条 FileInstall 源路径必须全部存在；
- `split_os_branches.py`：除 `If/ElseIf/Else/EndIf` 结构行外，不允许丢行或改行（`ElseIf` 会改写成等价的嵌套 `If/Else`）。
