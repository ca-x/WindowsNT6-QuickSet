# 模块结构说明

单文件脚本 `WindowsNT6+快速设置工具.au3`（原 12231 行）已按功能模块拆分，并按系统版本把版本相关实现单独成文件。

## 一、目录结构

```
WindowsNT6+快速设置工具.au3      入口/项目文件：只保留编译指令 + #include 清单
src\
├─ app\                          主流程（顺序敏感，勿调整 include 次序）
│   ├─ App_Init.au3              全局变量/常量、环境检测、加载动画、托盘菜单、单实例
│   ├─ App_MainWindow.au3        主窗口与各选项卡控件创建、事件绑定、初始数据装载
│   └─ App_MainLoop.au3          窗口显示、输入框回调注册、定时器、消息循环
├─ core\                         通用基础库（与业务无关）
│   ├─ Core_Utils.au3            字符串/数组/路径、系统与硬件信息、编解码
│   ├─ Core_WinAPI.au3           权限提升、LSA、SYSTEM 身份运行、窗口消息过滤
│   ├─ Core_Gui.au3              窗口/控件封装、皮肤与悬停、托盘、消息回调、加载动画
│   ├─ Core_Net.au3              IPHLPAPI 接口表、网卡信息、WMI 适配器、流量统计
│   └─ Core_Assets.au3           内嵌资源还原（base64/LZNT → bmp/ico/exe/vbs）
├─ features\                     功能模块，按功能域分目录
│   ├─ net\                      网络：NetTools / IpSet / MacChange / WifiShare / WOL / NCSI
│   ├─ system\                   系统优化：RegTweaks / Plugins / Services / SSD / Security / Cache / ProcessBL
│   ├─ shell\                    外壳：ExplorerMenu / ShellTweaks / Share / DirTransfer
│   ├─ personalize\              个性化：OemInfo / Wallpaper / ScreenSaver
│   ├─ account\                  账户与权限：UserAccount / SysRun
│   ├─ license\                  激活与授权：Activation
│   └─ tools\                    实用工具：TrayTools / FileCreate / DotNet / History / Insider / MkLink / ForceDel / TPHotkey
├─ os\                           按系统版本的优化实现（见第三节）
│   ├─ Os_Common.au3             @OSBuild > 6000 的通用实现与兜底分支
│   ├─ Os_Xp.au3                 Windows XP / 2003
│   ├─ Os_Vista7.au3             Vista / Win7 / 2008R2（6000 < build ≤ 8000）
│   ├─ Os_Win8.au3               Win8 / 8.1 / 2012（8000 < build ≤ 10240）
│   ├─ Os_Win10.au3              Windows 10（build > 9000）
│   ├─ Os_Win11.au3              Windows 11（build > 19040 / 21900 / 21990）
│   └─ Os_Server.au3             Windows Server 专属实现
├─ file\                         运行时载荷（FileInstall 源）与本地 UDF
└─ img\                          图片与图标资源（含编译图标 ToolIco.ico）

tools\                           拆分与迁移脚本（一次性使用，可留档）
backup\                          拆分前的原始单文件脚本快照
```

## 二、编译

入口文件仍在仓库根目录，AccAu3Wrapper 指令（`#PRE_*`）保持不变，直接编译即可：

```
AccAu3Wrapper_GUI 打开 WindowsNT6+快速设置工具.au3 → 编译
```

或使用 AutoIt 自带的 Aut2Exe：

```bat
Aut2exe.exe /in "WindowsNT6+快速设置工具.au3" /out "WindowsNT6+快速设置工具.exe" /x86
Aut2exe.exe /in "WindowsNT6+快速设置工具.au3" /out "WindowsNT6+快速设置工具_x64.exe" /x64
```

> 注：用 Aut2Exe 直接编译时不会写入版本号等资源信息（那是 AccAu3Wrapper 的 `#PRE_Res_*` 指令负责的），
> 程序标题里会显示 V0.0.0.0；用 AccAu3Wrapper 编译则正常显示 1.8.6.6。

## 三、按系统版本的实现（src\os）

原来注册表优化、插件安装等函数里混杂着大量 `If @OSBuild > xxxx Then … Else …` 分支，
现已把**分支正文**整体搬到 `src\os\Os_*.au3`，主流程只保留判断条件 + 一次函数调用：

```autoit
; src\features\system\Feat_RegTweaks.au3 —— AddRegTweaks()
If GUICtrlRead($Checkbox[1]) = $GUI_CHECKED Then
	If @OSBuild < 6000 Then
		_OsXp_AddRegTweaks_01()        ; 见 src\os\Os_Xp.au3
	Else
		_OsCommon_AddRegTweaks_02()    ; 见 src\os\Os_Common.au3
	EndIf
	$n += 1
EndIf
```

每个生成的函数头部都标注了**适用条件**与**来源**，例如：

```autoit
;-------------------------------------------------------------------------------
; _OsWin11_AddRegTweaks_22
; 适用条件：@OSBuild > 21990
; 来源：AddRegTweaks / 14跳过TPM和安全启动检查
;-------------------------------------------------------------------------------
Func _OsWin11_AddRegTweaks_22()
	RegWrite('HKEY_LOCAL_MACHINE' & $OSFlag & '\SYSTEM\Setup\LabConfig', 'BypassTPMCheck', 'REG_DWORD', '00000001')
	...
EndFunc
```

涉及的文件与条件对照：

| 文件 | 对应条件 |
| --- | --- |
| `Os_Xp.au3` | `@OSBuild < 6000`、`@OSVersion = 'WIN_XP' / 'WIN_2003'` |
| `Os_Common.au3` | `@OSBuild > 6000` 的通用分支、其余兜底分支 |
| `Os_Vista7.au3` | `6000 < @OSBuild ≤ 8000`（含 `ElseIf @OSBuild < 8000 And @OSBuild > 6000`） |
| `Os_Win8.au3` | `@OSBuild > 8000` / `@OSBuild < 10240`、`@OSVersion = 'WIN_8' / 'WIN_81'` |
| `Os_Win10.au3` | `@OSBuild > 9000`、`@OSVersion = 'WIN_10'` |
| `Os_Win11.au3` | `@OSBuild > 19040 / 21900 / 21990` |
| `Os_Server.au3` | `@OSVersion = 'WIN_2003' / 'WIN_2008' / 'WIN_2008R2'`，以及 `Win08ServiceTweaks()` |

要改某个系统上的行为，直接打开对应文件即可，不用再在几千行里翻找。

## 四、维护须知

1. **FileInstall 的相对路径以「主脚本所在目录」为基准**（不是当前工作目录，也不是 include 文件所在目录）。
   主脚本在根目录，所以载荷路径写作 `FileInstall('.\src\file\xxx.exe', …)`。
   挪动 `src\file\` 时必须同步修改所有 FileInstall 源路径。
2. **主流程 include 顺序不能改**：`src\app\App_Init.au3` → `App_MainWindow.au3` → `App_MainLoop.au3`
   是顶层可执行代码，按顺序执行。其余模块只包含函数定义，顺序无关。
3. **新增模块**：在 `src\features\<功能域>\` 下新建文件后，记得在入口文件的 `#Region` 里加一行 `#include`。
4. 各模块文件顶部有 `#include-once`，模块头注释里写明了模块职责与函数数量。
5. AutoIt 里 `Local` 在文件作用域等价于 `Global`，因此跨 include 使用这些变量是安全的。

## 五、迁移脚本（tools\）

| 脚本 | 作用 |
| --- | --- |
| `split_modules.py` | 从 `backup\` 里的单文件原始脚本重新生成全部模块与入口文件（幂等） |
| `fix_paths.py` | 目录规范化后的路径修正：`file\` → `src\file\`、`ToolIco.ico` → `src\img\ToolIco.ico`，并校验所有 FileInstall 源文件存在 |
| `split_os_branches.py` | 把 `AddRegTweaks()` / `pluginsTweaks()` 中的版本分支搬进 `src\os\`，并做内容守恒校验 |

重新生成整套目录（顺序不能颠倒）：

```bat
python tools\split_modules.py
python tools\fix_paths.py
python tools\split_os_branches.py --apply
```

三个脚本都带校验：

- `split_modules.py`：449 个函数必须全部有归属，且拆分前后内容逐行一致；
- `fix_paths.py`：45 条 FileInstall 源路径必须全部存在；
- `split_os_branches.py`：除 `If/ElseIf/Else/EndIf` 结构行外，不允许丢行或改行（`ElseIf` 会改写成等价的嵌套 `If/Else`）。
